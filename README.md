# Jennifer Evangelista

**Data engineering, architecture, and applied AI.**

I work through technical questions with Python, SQL and PySpark, using small, reproducible examples with explicit data contracts, tests, and execution limits. My public work covers data quality, CDC, join cardinality and freshness; applied AI is also documented as a learning journey.

## Current work

- **[Data Engineering Lab](https://github.com/jenniferevangelista-de/data-engineering-lab)** — Python/SQLite sales aggregation, deterministic CDC batch preparation in PySpark, Community SQL examples, JSON value preservation, [join-cardinality checks](https://github.com/jenniferevangelista-de/data-engineering-lab/tree/main/sql/day_002_join_cardinality), and a [freshness contract](https://github.com/jenniferevangelista-de/data-engineering-lab/tree/main/airflow/day_001_freshness_contract). Tests use synthetic data and local Python, SQLite and Spark in GitHub Actions. Airflow scheduler, AWS, Kafka and Databricks workspace integrations remain unvalidated.
- **[CS50 AI learning portfolio](https://github.com/jenniferevangelista-de/cs50-ai-learning-portfolio)** — a learning record covering search, logic, probability, machine learning, computer vision and NLP. Public documentation describes concepts and reported course results; assessed solutions remain private.
