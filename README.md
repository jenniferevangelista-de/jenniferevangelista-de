# Jennifer Evangelista

Data engineering with Python, SQL and PySpark. I build small, reproducible examples with explicit data contracts, tests, and execution limits, and document what I learn about data quality, CDC and applied AI.

## Current work

- **[Data Engineering Lab](https://github.com/jenniferevangelista-de/data-engineering-lab)** — sales aggregation in Python and SQLite, deterministic CDC batch preparation in PySpark, and SQL examples derived from Databricks Community discussions. Tests use synthetic data in local Spark and GitHub Actions. AWS, Kafka and Databricks workspace integrations are documented as pending, rather than validated deployments.
- **[CS50 AI learning portfolio](https://github.com/jenniferevangelista-de/cs50-ai-learning-portfolio)** — a learning record covering search, logic, probability, machine learning, computer vision and NLP. Public documentation describes concepts and reported course results; assessed solutions remain private.
